# Changelog

## 0.2.0 - 2026-10-05

- Se sustituyó la página vertical por un shell de aplicación técnica con navegación modular, paneles internos e inspector fijo.
- Todos los bloques de entrada del perfil T-78 se expusieron como workspaces editables con estado de borrador, validación y revisiones inmutables.
- Se añadió feedback visible para guardado, cálculo y errores, junto con historial de revisiones y runs.
- La traza de cálculo pasó a un drawer accesible desde resultados, tablas y verificaciones.
- El visor 3D incorporó 192 planchas de casco seleccionables, costuras alternadas, zonas de fondo, anclajes y domo geodésico representativo.
- Se añadió selección cruzada entre árbol, visor e inspector, modos de visualización, aislamiento y color por resultados.
- Se ampliaron los endpoints de revisión, geometría, resultados, traza e historial.
- Se añadieron pruebas de integración de API y flujo de usuario frontend.
- Se documentó la arquitectura UX v0.2 y se actualizó la bitácora de auditoría.

## 0.1.1 - 2026-10-04

- Se añadió una bitácora integral de desarrollo y una guía de auditoría independiente.
- Se registraron hashes SHA-256 de las fuentes, evidencia de pruebas, limitaciones y deuda técnica conocida.

## 0.1.0 - 2026-10-04

- Descubrimiento documental y registro de conflictos T-78.
- Fixture dorado con procedencia.
- Motor One-Foot y cadena sísmica auditable.
- Verificaciones de fondo, anclajes, sillas y pesos.
- SQLAlchemy/SQLite con revisiones inmutables y auditoría.
- FastAPI y endpoints para n8n, batch, exportaciones y backup.
- React/TypeScript/Three.js con interfaz clara y panel de trazas.
- Generación OpenSCAD y reportes HTML/PDF/JSON.
